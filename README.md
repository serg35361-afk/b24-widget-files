# 📁 Файлы виджета для Битрикс24

В этой папке лежат **готовые файлы** виджета, которые нужно загрузить на GitHub.

## 📋 Что здесь есть:

### 1. `index.html` — Основной файл виджета
Содержит HTML, CSS и JavaScript код виджета.

**Что нужно изменить перед загрузкой:**
- Строка 100: `const SMART_TYPE_TITLE = 'Название вашего Смарт-процесса';`
  - Замените на реальное название вашего Смарт-процесса
- Строка 102: `const FILE_FIELD_CODE = 'UF_CRM_FILE_FIELD';`
  - Замените на UF-код поля с файлами в вашем Смарт-процессе
- Строка 127: `const smartId = deal['UF_CRM_SMART_LINK'];`
  - Замените `UF_CRM_SMART_LINK` на UF-код поля привязки к Смарт-процессу
- Строка 133: `entityTypeId: 'DYNAMIC_XX'`
  - Замените `XX` на ID вашего типа Смарт-процесса (можно найти в настройках Смарт-процесса)

### 2. `manifest.json` — Описание приложения
Содержит метаданные для Битрикс24.

**Что нужно изменить перед загрузкой:**
- Строка 4: `"HANDLER": "https://ВАШ-САЙТ.netlify.app/index.html"`
  - Замените `ВАШ-САЙТ` на реальное имя вашего сайта на Netlify
  - Например: `"HANDLER": "https://bitrix-smart-files.netlify.app/index.html"`

## 🚀 Как использовать:

### Способ 1: Копирование через браузер GitHub
1. Откройте файл `index.html` в этой папке
2. Скопируйте весь код (Ctrl+A → Ctrl+C)
3. Перейдите на GitHub → ваш репозиторий → Add file → Create new file
4. Введите имя файла: `index.html`
5. Вставьте код в редактор
6. Нажмите «Commit new file»
7. Повторите для `manifest.json`

### Способ 2: Drag & Drop
1. Откройте папку `widget-files` в проводнике/Finder
2. Перейдите на GitHub → ваш репозиторий → Add file → Upload files
3. Перетащите оба файла (`index.html` и `manifest.json`) в зону загрузки
4. Нажмите «Commit changes»

## ⚠️ Важно!

- **Не забудьте изменить конфигурацию** в `index.html` перед загрузкой
- **Укажите правильный URL** в `manifest.json` после деплоя на Netlify
- Файлы должны лежать в **корне репозитория** (не в подпапке)
